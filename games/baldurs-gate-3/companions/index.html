Baldur's Gate 3 Companions

A reference hub for party members, party roles and companion-specific quest coverage.

Baldur's Gate 3 is built around party-based adventuring and reactive relationships. Companion choice affects both story experience and party composition, but those two decisions do not have to be treated as the same thing.

Core Origin companion pages

GameHelpX currently covers Shadowheart, Astarion, Gale, Lae'zel, Wyll and Karlach with role-focused pages that connect each companion to relevant class and party-planning content.

Choose companions for story, then adjust the role

If you strongly prefer a companion's story or personality, you do not have to remove them just because the default class duplicates another role. BG3 allows class changes, so party structure can remain flexible.

What each companion page should answer

  • Default class and natural role
  • Where the companion fits in a party
  • Relevant build and class pages
  • Quest or relationship links as the site expands
  • Alternative role ideas when the default party overlaps

Party balance

Use Party Composition and the Party Role Planner when deciding which companion fills the fourth slot. The goal is not a universal ranking; it is covering the problems your current group actually faces.
