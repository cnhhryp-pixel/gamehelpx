Baldur's Gate 3 Multiclassing

A build-planning hub for combining levels across BG3's 12 classes.

BG3 offers 12 classes and a large subclass pool, creating a wide build space when class levels are combined.

What to plan before multiclassing

  • Your primary combat or support role
  • Which class features need deeper level investment
  • Ability-score requirements for the playstyle you want
  • Whether the second class adds a unique mechanic or only duplicates tools you already have

Why separate multiclass pages matter

A useful multiclass guide should explain the leveling order, the role of each class, and the tradeoffs. GameHelpX will build combination-specific pages rather than publishing one giant list.
