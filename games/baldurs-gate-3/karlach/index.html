Karlach Guide

A companion reference for Karlach.

Karlach is an Origin companion whose default class is Barbarian. Her starting identity is built around aggressive frontline melee and Rage.

Party role

She fits parties that need a durable melee attacker and strong close-range pressure. Her default subclass path is Berserker if left unchanged.
