Baldur's Gate 3 Feats

A build-oriented reference for deciding when a feat should support damage, defense, utility or role-play.

Feats are one of BG3's most important character-customization decisions because they can improve damage, defense, concentration, mobility or utility. The best choice depends on the character's job, not on a universal ranking.

Start with the build's main role

A frontline character, ranged attacker, controller and support caster all value different upgrades. Decide what the build is trying to accomplish before comparing feats.

Four common feat goals

  • Damage: improve the weapon or spell pattern you already use.
  • Defense: increase durability or make concentration easier to maintain.
  • Mobility: reach useful positions more reliably.
  • Utility: add skills, flexibility or a specific feature the party lacks.

Feat versus ability improvement

Do not choose a feat only because it sounds interesting. Compare it with improving a core ability score and ask which option produces more value for the character's actual role.

Think about the whole party

A feat that solves a party-wide weakness can be more useful than one that slightly increases personal damage. Use Party Composition and the role planner before committing when the choice is not obvious.
