Baldur's Gate 3 Rogue Build

A Rogue planning hub for stealth, skill utility and burst damage.

Rogue combines exploration utility with burst-oriented combat options. A useful Rogue build starts by deciding whether the character's main value comes from stealth, ranged damage, melee pressure, skill coverage or a multiclass combination.

Choose the role first

  • Stealth and scouting
  • Lockpicking and trap disarming
  • Ranged burst damage
  • Melee finesse
  • Multiclass utility

Skill coverage

One of Rogue's biggest party benefits is handling skill checks that other characters may not cover. Make sure the build preserves the exploration role you actually need rather than focusing only on combat numbers.

Ranged versus melee

A ranged setup can make positioning and stealth easier, while melee requires more careful movement and party support. Choose one direction first so feats and equipment reinforce the same plan.

Multiclass planning

Rogue is often considered for multiclassing because some features arrive early, but every level spent elsewhere changes what deeper Rogue progression you receive. Test the split against the level-12 cap before committing.

Party fit

If another companion already covers stealth and lockpicking, you may want the Rogue to specialize more aggressively in combat—or choose another class entirely.
