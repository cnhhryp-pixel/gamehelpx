Baldur's Gate 3 Classes & Subclasses

A build-planning reference for choosing a class before diving into individual build pages.

Baldur's Gate 3 has 12 classes: Barbarian, Bard, Cleric, Druid, Fighter, Monk, Paladin, Ranger, Rogue, Sorcerer, Warlock and Wizard. Larian's current game overview lists 46 subclasses across those 12 classes.

How to choose a starting class

Start with the role you want to perform most often. Martial classes emphasize weapon combat and durability; full casters lean on spell access and resource management; hybrid classes can mix martial and magical tools. Your class also affects dialogue and role-play options.

Multiclassing

BG3 supports multiclassing, letting one character combine levels from different classes. That opens a very large build space, so GameHelpX will keep class reference pages separate from specific build recommendations.
