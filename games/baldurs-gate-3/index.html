BG3 FAQ

Where should I start if I am building a party?

Start with Party Composition and the Party Role Planner, then open Classes, Companions and specific build pages for the roles your party still needs.

When should I use the Multiclass Level Planner?

Use it after you know which two classes you want to combine. It checks the level budget so you can test splits without losing track of the level-12 cap.

Which BG3 pages will grow next?

The strongest next additions are more class-specific builds, companion-specific pages, subclass pages and decision-oriented quest references.
