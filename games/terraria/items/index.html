Terraria Items Database

Terraria's enormous item surface is a natural fit for structured database pages.

Terraria's item system is enormous, so a useful database needs structure. Searching one alphabetical list is less helpful than grouping items by what they do, where they come from and when they become relevant.

Main database categories

  • Weapons and ammunition
  • Armor and accessories
  • Tools and crafting stations
  • Potions and utility items
  • Mounts, minions and wings
  • Materials, ores and bars

Progression context

An item can be strong but irrelevant if the required material, boss or biome is not available yet. Each future item page should therefore connect acquisition to progression stage.

Crafting chains

Some items are built through several upgrades. Showing the whole chain is more useful than listing only the final recipe because players can see which component is actually blocking progress.

How GameHelpX will expand this section

The next useful layers are weapon categories, accessory upgrade chains, crafting materials and progression-specific item groups before expanding into thousands of individual pages.
