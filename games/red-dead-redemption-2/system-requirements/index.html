Red Dead Redemption 2 PC System Requirements

Rockstar's current PC minimum and recommended hardware requirements.

Minimum

  • Windows 10 64-bit
  • Intel Core i5-2500K or AMD FX-6300
  • 8 GB RAM
  • GTX 770 2 GB or Radeon R9 280 3 GB
  • 150 GB disk space

Recommended

  • Windows 10 64-bit
  • Intel Core i7-4770K or Ryzen 5 1500X
  • 12 GB RAM
  • GTX 1060 6 GB or Radeon RX 480 4 GB
  • 150 GB disk space

What these requirements mean

The minimum list tells you whether the game is expected to run at all; the recommended list is a better starting point for a smoother general experience. Exact performance still depends on resolution, graphics settings, drivers and background load.

Storage planning

Rockstar lists 150 GB of disk space, so leave extra free space beyond the bare requirement for updates, shader data and normal system overhead.

Before troubleshooting performance

  • Update graphics drivers.
  • Check that the game is using the intended GPU.
  • Close unnecessary background applications.
  • Lower the most demanding settings before assuming the hardware is unsupported.
