Cyberpunk 2077 Perks

Perks should be planned together with attributes, cyberware and weapon choice.

Cyberpunk 2077's current build system is designed around distinct playstyles. The official Build Planner lets players test perk trees before committing points in-game.

How to plan perk pages

  • Start with a playstyle goal
  • Prioritize the attribute tree that supports it
  • Connect perk choices to cyberware and weapons
  • Separate leveling order from endgame setup

Source: Official Cyberpunk 2077 Build Planner.
