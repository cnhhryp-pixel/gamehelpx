Cyberpunk 2077 Netrunner Build

A hacking-focused hybrid build inspired by CD PROJEKT RED's official Hack-&-Slash Netrunner.

CD PROJEKT RED's Hack-&-Slash Netrunner concept is built around heavy Intelligence investment, quickhack combinations and strong RAM recovery while still allowing aggressive close-range play.

Core build identity

  • High Intelligence investment
  • Quickhack chains and combinations
  • RAM recovery and management
  • Close-range backup options instead of pure passive hacking

Quickhack planning

Choose quickhacks that work together instead of filling every slot with unrelated effects. A useful setup needs reliable general pressure plus tools for tougher enemies, groups or specific combat situations.

RAM economy

If the build regularly runs dry, check recovery, perk support and hack order before simply adding more resources. Efficient sequencing can matter as much as raw capacity.

Cyberware and perks

Cyberware and perks should reinforce the same loop: faster hacking, safer positioning, better survivability or stronger follow-up damage. Avoid spreading investment across playstyles that rarely interact.

When this build fits

This style suits players who want hacking to remain the main identity but still prefer a more active combat rhythm than sitting at long range for every encounter.
