Cyberpunk 2077 Netrunner Build

A hacking-focused hybrid build inspired by CD PROJEKT RED's official Hack-&-Slash Netrunner.

CD PROJEKT RED's Hack-&-Slash Netrunner is designed around Intelligence-heavy investment, RAM recovery and aggressive quickhack combinations while still giving the player close-range combat options.

Core idea

  • Prioritize Intelligence early
  • Build around quickhack combinations
  • Improve RAM recovery
  • Add close-range tools instead of playing only from cover

Use the official Build Planner to test perk allocation before spending points in-game.

Source: CD PROJEKT RED — Hack-&-Slash Netrunner.
