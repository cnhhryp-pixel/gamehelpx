Stardew Skull Cavern Target Planner

Turn a target floor into a simple descent plan before the run begins.

This is a planning estimate, not a prediction. Enter the floor you want to reach, how many staircases you are willing to use, and the shaft skips you expect to gain during the run.





Plan

Enter a target to calculate.

How to read the estimate

The planner starts from floor 1, subtracts planned staircase descents and expected shaft skips, then shows the approximate floors that still need ordinary ladders or additional shafts.

Use it to choose a strategy

If the remaining descent is very high, bring more staircases or focus more aggressively on finding shafts. If it is low, you can spend more time on ore and loot.

Randomness still matters

Skull Cavern layouts and shaft opportunities vary. Use the number as a preparation target, not a promise that the run will follow the estimate.
