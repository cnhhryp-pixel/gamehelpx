Stardew Artisan Value Calculator

Compare raw versus processed value without hard-coding one crop or machine.

This calculator is intentionally generic: enter the raw sale price and the processed sale price you want to compare. That keeps it useful across different crops, animal products and artisan machines.




Result

Enter values to compare.

What the result means

The calculator compares gross sale value only. It does not subtract seed cost, machine crafting cost, processing time or opportunity cost.

Machine time matters

A larger sale-price increase is not automatically the best use of machines if processing takes a long time and a backlog forms. Use this together with your real machine capacity.

Keep some raw goods

Bundles, gifts, cooking and quests can require unprocessed items, so do not automatically convert every harvest just because the processed value is higher.
