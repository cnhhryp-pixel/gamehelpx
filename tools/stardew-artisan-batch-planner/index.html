Stardew Artisan Batch Planner

Turn a pile of raw goods into a machine-capacity plan.

This planner estimates how many machine cycles you need for a batch of raw items. It is generic so you can use it for Kegs, Preserve Jars or another processing setup by entering your own values.





Batch result

Enter a batch to calculate.

What the planner tells you

It estimates the number of machine cycles, total machine-hours across all cycles, elapsed processing hours if every machine is kept busy, and gross processed sale value.

Use the result to find the bottleneck

If the item backlog requires many cycles, adding machines may help more than increasing crop production. If machines sit idle, raw supply is the bigger constraint.

Gross value is not profit

The planner does not subtract seeds, machine crafting cost, input opportunity cost or labor. Use it for capacity planning, not accounting.
