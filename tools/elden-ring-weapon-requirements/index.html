How the Strength check works

When two-handing is enabled, the tool multiplies your Strength by 1.5 for the requirement check. It does not change Dexterity, Intelligence, Faith or Arcane.

Requirement check is not build quality

Meeting the minimum requirement only means the weapon can be used properly. Scaling, upgrade level, weapon skill, stamina use and your actual moveset preference still matter.

Use it before spending levels

If one stat is short by only a few points, compare that cost with the rest of your build before leveling. The Stat Planner can help you see what those points replace elsewhere.
