Elden Ring Stat Budget Planner

Allocate a custom pool of extra stat points before deciding where your build should invest.

Allocate points, then check your budget.

This is a planning tool for extra points only. Starting class and exact character level are intentionally not assumed.

What this planner does

The tool helps you divide a custom pool of extra attribute points across Vigor, Mind, Endurance, Strength, Dexterity, Intelligence, Faith and Arcane. It does not assume a starting class or exact Rune Level, so you can use it for rough planning at different stages of a build.

Start with the build's job

Decide what the character is trying to do before allocating points. A Strength build, Dexterity build and sorcery build all value different offensive stats, but each still needs enough survivability and resource support to function.

Common planning mistake

Do not spend every available point on the main damage stat. Vigor, Endurance or Mind may solve a more important problem if you are dying too quickly, running out of stamina or running out of FP.

Suggested workflow

  1. Set the number of extra points you want to plan.
  2. Reserve points for survivability and resources first.
  3. Allocate the remaining budget to the build's primary offensive stats.
  4. Compare the result with the specific build guide and boss content you are preparing for.
