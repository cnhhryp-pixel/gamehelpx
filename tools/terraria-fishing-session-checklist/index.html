Terraria Fishing Session Checklist

Prepare the location and goal before spending time fishing.

This checklist is for targeted fishing sessions. It stores progress locally in your browser and can be reset between trips.

Session checklist

Start from the target

Quest fish, crates, potion ingredients and biome-specific catches have different requirements. Pick the reward first, then build the session around it.

Do not confuse fishing power with location

Better gear can improve the session, but the wrong biome or layer still produces the wrong loot table.
