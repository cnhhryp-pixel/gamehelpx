Stardew Valley Gift Finder

Search all 12 marriage candidates by name and jump to their detailed page.

How to use it

Type a marriage candidate's name to see their birthday and a few remembered loved-gift examples, then open the full character page for more context.

Best way to plan gifts

Do not try to memorize every possible gift at once. Pick one or two practical items for the villagers you actually want to prioritize, then reserve birthday gifts ahead of time.

What to check next

  • Use the Calendar page so birthdays do not surprise you.
  • Use the Marriage Candidates index to compare all 12 candidates.
  • Open the main Gifts hub when you need broader friendship guidance.
