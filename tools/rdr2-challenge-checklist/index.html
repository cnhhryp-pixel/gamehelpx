RDR2 Challenge Checklist

Track the nine major story-mode challenge categories locally in your browser.

Use this checklist to track the nine story-mode challenge categories in Red Dead Redemption 2. Progress is stored locally in your browser, so you can close the page and return later on the same device.

How to use it

  1. Check a category when you have completed the challenge line you are tracking.
  2. Leave incomplete categories unchecked.
  3. Use Reset only when you want to clear all local progress.

What the categories cover

The challenge system spans exploration, hunting, shooting, survival, horse riding and gambling. Treat this as a high-level completion tracker rather than an item-by-item walkthrough.

Progress is saved only in this browser on this device.
