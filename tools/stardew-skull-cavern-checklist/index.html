Skull Cavern Prep Checklist

Check the essentials before leaving for a deep Skull Cavern run.

This checklist focuses on preparation rather than floor-by-floor instructions. Your selections are stored locally in this browser.

Before the run

Use the checklist with a run goal

A depth run and a resource run are different. If the goal is descent, skip low-value detours. If the goal is ore, accept slower floor progress in exchange for better resource collection.

Local-only storage

No account is required. The checklist stays in the current browser and can be reset at any time.
