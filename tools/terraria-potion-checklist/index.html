Terraria Potion Checklist

Track the common potion categories you want ready before a boss or resource run.

This checklist is intentionally reusable. It does not claim every potion is required; check only the categories that matter for the current goal.

Checklist

Use categories instead of one fixed list

Bosses, mining sessions and fishing trips need different preparation. A category checklist stays useful without pretending one consumable loadout fits every activity.

Build a repeatable stock

Keep ingredients for the few buffs you use often. Sustainable preparation is better than farming a huge one-time set before every encounter.
