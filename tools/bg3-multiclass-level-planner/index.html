BG3 Multiclass Level Split Planner

Test two-class level splits and make sure the total fits BG3's level-12 character cap.




Result

6 Paladin / 6 Warlock = level 12.

This tool checks only the level budget. It does not rank builds.

How to use the planner

Enter two classes and the number of levels you want in each. The tool only checks whether the total fits BG3's level-12 cap; it does not tell you that one split is stronger than another.

What to decide before splitting levels

  • Which class provides the character's main combat role?
  • Which features require deeper investment in one class?
  • Which class is being added for a specific feature rather than just variety?
  • Does the split still leave the party's other roles covered?

Useful workflow

Start from the role you want the character to perform, choose the minimum class levels needed for the core features, then use the remaining levels to test alternatives. This avoids building around a popular split without knowing what each class is contributing.
