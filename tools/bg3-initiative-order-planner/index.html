BG3 Initiative Order Planner

Enter each character's roll and bonuses to preview the party's initiative order.

BG3 initiative uses a d4 roll plus initiative modifiers. This planner keeps the roll manual so you can reproduce an actual combat roll or test several opening-order scenarios.

Party entries

Columns: name · d4 roll · Dexterity modifier · other initiative bonus.

Order

Use the order to plan the opening round

Acting earlier can let a controller shape the battlefield, a burst character remove a dangerous target, or a frontline character occupy space before enemies move.

Do not optimize initiative in isolation

Higher initiative is useful only when it supports the build's real job. Keep ability scores, survivability and damage priorities in balance.
